## Tableau Ask Data
### Features
1. Allowes users to ask questions regarding data in plain english
2. It tries to understand the question and generates data visualization
3. Can autocomplete queries
4. Maintains a history of user's queries
5. Can export visualization in formats such as PNG and PDF.
### Working
1. Tableau Ask Data uses NLP (important to note it does not use generative AI).
2. It breaks down queries into keywords.
3. These Keywords are then searched in the workbook which is the user's dashboard.
4. When data is found it generates a visualization
### Important Takeaway
1. Tableau Ask Data uses NLP and can autocomplete keywords that it finds in the user's workbook.
2. It does not use generative ai; however, the upcoming Tableau GPT and Tableau Pulse will use generative ai and will be far more powerful that Ask Data.
3. To use this feature, the user first has to set up his workbook which requires technical expertise to some extent.
4. User also needs to be aware of natural language capabilities to phrase their query in a way this tool can understand.
### Availability
This feature is available inTableau Desktop Professional and Tableau Online Professional editions.

## Chartify
#### [website](https://www.chartify.ai/)
Chartify, available as a web app and a mobile app, is tool that uses generative ai to create data visualizations.
### Features
1. User have to add a data source like a CSV file or a database connection like Postgres.
2. User can then select columns/tables to create visualizations.
3. It does not support natural language or plain english input for generating visualizations
### Availability
1. Free use only provides 5 visualizations.
2. Paid version allows unlimited visualizaions.
3. This service has been suspended by its owner.

## GenBI
GenBI is an open-source project that uses generative AI to create BI data visualizations.
### Usage
1. The GenBI model first has to be trained.
2. Can generate a variety of visualizaitons.
3. It is still under development so may not be as accurate.
4. Does not have a user inteface.
